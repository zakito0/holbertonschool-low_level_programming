# C - Hello, World

This project covers the basics of C programming and the GCC compilation process at Holberton School:
* The four stages of compilation: Preprocessing, Compilation, Assembly, and Linking.
* Writing simple C programs using `puts` and `printf`.
* Determining data type sizes using `sizeof`.
* Standard file descriptors and writing directly to `stderr`.
* Adhering strictly to the Betty coding style.
